# Bayonetta Archipelago

This repository contains the open-source source code for the **Bayonetta** Archipelago randomizer, client (`BayoHook`), and associated logic files.

## Open Source
This project is completely open-source and free for anyone to use, study, modify, and distribute. Contributions, forks, and feedback are always welcome! Please see the [LICENSE](LICENSE) file for more details.

## Project Structure
- `APWorld/` - The Archipelago game world logic.
- `BayoHook-main/` - The C++ source code for the game integration client.
